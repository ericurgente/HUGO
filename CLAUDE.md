# ROTO — contexto del proyecto

Este archivo pone al día cualquier chat nuevo sobre este sitio. No tocarlo salvo para actualizar datos.

## Qué es
Portfolio de una sola página de **ROTO** (ropa técnica / armadura urbana). Marca: REVO Studios.

## Archivos
- `index.html` — el sitio **entero**: HTML, CSS y JS dentro del mismo archivo. No hay build, ni frameworks, ni dependencias que instalar.
- `assets/` — 21 archivos: fotos optimizadas, `roto-film.mp4`, `favicon.png`, `og-cover.png`. Todas las rutas son relativas (`assets/…`).
- Peso total: ~6,8 MB.

## Dónde está publicado
- **Hosting:** Vercel, con dominio propio ya apuntado.
- **Sin repositorio de GitHub conectado.** Se despliega arrastrando esta carpeta (drag & drop), así que **cada actualización es un drop manual nuevo** sobre el mismo proyecto de Vercel. El dominio se mantiene.
- Vercel exige que el archivo se llame `index.html` — no renombrarlo.

## Cómo publicar un cambio
1. Se edita `index.html` en el chat.
2. Se descarga la carpeta completa.
3. Se suelta en vercel.com, sobre el proyecto existente.
4. Listo en ~20 segundos, mismo dominio.

## Tipografía
- Google Fonts: **Archivo**, **Archivo Black**, **JetBrains Mono** → el sitio necesita internet para verse correcto.
- El display usa **Anzeige Grotesk**, que **no está incluida** por licencia: ahora mismo cae en Archivo Black. Para el diseño exacto hay que comprar la licencia y añadir el archivo del font.
